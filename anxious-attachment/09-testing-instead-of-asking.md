# 9. Testing Instead of Asking

> A test asks the question without asking it.

The direct question feels dangerous, because it can be answered with a no.

So it is put indirectly — going quiet, withdrawing, hinting, saying nothing is wrong.

The purpose is to see whether the other person notices and comes closer.

If they come, it proves nothing, because the situation was arranged.

If they do not come, it is taken as proof of the fear.

A test can only confirm the fear. It cannot disprove it.

The partner usually knows they are being tested, and sees only the indirectness.

No amount of testing produces the certainty it is looking for.
